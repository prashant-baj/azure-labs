# Case repository — starter kit

One repository per group. Everything your group produces from Session 5 onwards lives here.

```
docs/        what Module 1 produced — problem statement, evidence log, concern sheet, decision log
specs/       what Module 2 produces — solution definition, integration decisions, contracts, ADRs, NFRs
templates/   the formats. Copy, do not redesign
prompts/     the prompts for each session, word for word
CLAUDE.md    how the assistant works on this case
```

## The rule that changes every session

| Session | The assistant is allowed to |
|---|---|
| 5 | **Review** your work. It may not write any of it |
| 6 | **Offer options** — you choose and defend |
| 7 | **Draft** contracts and ADRs — you find what is wrong with them |
| 8 | **Argue against** your requirements — you decide what survives |

Whatever the rung, you sign the document. It does not.

## Commit discipline

- Commit before you show anything to the assistant. That commit is your own thinking, on record.
- Commit again after you have decided what to accept. Keep both.
- One line per commit message, saying what changed and why — the same discipline as a decision log.
