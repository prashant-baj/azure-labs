# Session 6 prompt — it offers options, you choose

One seam per prompt. Three seams in one prompt gets you three shallow answers.

## The options prompt

> Here is the case background and our solution definition. For the seam between **[A]** and **[B]**,
> give three integration options. For each one: the shape — request and response, events, or file —
> what it costs us, what it costs them, and what would make it the wrong choice.
> **Do not recommend one.**

## Then, for the option you are leaning towards

> For option [X], what would have to be true about [B] for this to be a bad choice?
> Answer only from what our case says, and say plainly where the case is silent.

## Before you accept any of it
- Does each option cost **both** sides something? An option that only costs them is not an option.
- Can you say, in one line, why each rejected option lost?
- Did it sneak in a recommendation? If so, ignore that part and choose yourselves.

**A decision record with no rejected options is a preference, not a decision.**
